Bug paths

where the config can be held together in theory and slip in practice

breaks the secret guard has two front doors

The rule: a subagent must never read a live secret, however the command is spelled.

Session start ▶ Tool call proposed ▶ read .env / bash grep .env ▶ Denied ▶ model reroutes

Leaves out: the declarative deny list in .claude/settings.json covers Write and Edit only, and the Claude pre-tool-use.sh hook only warns. Reads through read or bash (cat .env, rtk grep .env, xargs cat) are denied only by the OpenCode plugin, and .env.example is exempt on purpose.

mayBreak the budget nudges, it never blocks

The rule: exploratory shell must turn into edits.

Turn open ▶ exploratory call ×3, 0 edits ▶ L1 nudge ▶ ratio >3 after 5 edits ▶ L2 "bash-budget:" line ▶ still no deny

Leaves out: the L3 deny is deliberately not implemented, so "every gate passes" can be true with zero steering accepted. Unknown Bash commands are not counted at all.

bugPath a lost marker silences the ping

The rule: notify only when the last dispatched subagent has stopped.

Subagent dispatch ▶ marker added ▶ worker ends ▶ SubagentStop pops the oldest marker ▶ a marker it cannot match stays forever ▶ Stop allowed, no notification

Leaves out: the counter is a directory of files, not a number, and subagent-stop.sh is deliberately not id-matched because the tool ids cannot be reconciled across hooks.
