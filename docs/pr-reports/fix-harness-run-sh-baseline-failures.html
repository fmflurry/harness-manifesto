CI

Before, CI ran only RUN_ONLY=guard, which is how a regression breaking 70 tests went unnoticed. Now the git-guard workflow adds a Full harness suite step on ubuntu (mawk, gawk) and macOS. Windows stays on the guard subset, with the reason in the workflow: its guard job alone takes about 13 minutes, and the suite's worktree, symlink and POSIX-path fixtures have never run under Git Bash.
