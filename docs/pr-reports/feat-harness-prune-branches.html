agent-harness prune-branches [--confirmed]

Removes local branches that are already merged into origin/<base>. Without --confirmed it only lists what it would delete. It never touches remotes.

Decision flow, per local branch

1 · skipbackup/* (prune-backups owns these), the base branch, the current branch
2 · keepsymbolic refs, branches named in a goal file or registry entry, branches checked out in any worktree
3 · keepjudged against the sha git ls-remote origin <base> reports: tip equal to it (no commits of its own yet), or tip not an ancestor of it
4 · deletedry run prints would be deleted; --confirmed runs update-ref --no-deref -d ref sha

Risks

This is a new command that deletes branches. It only deletes local refs whose tip is reachable from the base tip origin reports, and never one that a goal or worktree claims. A deleted branch can be recreated from origin or the reflog. The proof is the sha origin reports at run time, kept in a variable, so rewriting a local ref before or during the run proves nothing. Origin's URL is still the trust root, as for ship-merge and cleanup: repointing it is a harness-wide follow-up. It is listed under Locked decisions for Florian.
