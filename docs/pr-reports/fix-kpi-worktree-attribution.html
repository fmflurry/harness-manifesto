KPI events follow the worktree

Orbit printed “0 claude, 0 cursor, 0 opencode” for work that happened. The hook was labeling every call with the shell’s checkout, while kpi feature kept only the feature branch.

Before

1

The hook process stays on master. /ship never cds.

2

The tool runs in the worktree: git -C, cd … &&, or an absolute path.

3

The event is stored as master. The feature report looks up feat/… and finds nothing.

4

A review or a guard with no session still marked the report complete, so the zeros looked confirmed.

After

1

Claude, Cursor, and OpenCode pass the payload directory, the shell command, and the file path. The command is not stored.

2

The command is walked left to right. cd with && or ;, parentheses, and git -C . keep the last worktree. A drive letter or UNC path counts as absolute.

3

ship-init and goal write session_bind. Later events with no directory use that binding.

4

A Session-Id trailer on the branch counts a session that already has an event. No event, no invented session.

5

Missing capture is N/A, with a coverage reason. A real zero appears only after session events were collected.

Directory, in order

Walk the command and keep the last checkout → tool file path → payload cwd → session binding → hook directory. cd moves the simulated directory on && or ;. git -C and --work-tree resolve from there.

What the tests lock

  • Real git worktree add repos: payload cwd, git -C, cd, absolute path, a file path, and seven chained commands that must end on feat/widget or feat/other.
  • goal status inside a linked worktree, and ship-init against a local bare origin, write session_bind for that branch.
  • A session id containing / or .. does not create a task marker outside the home directory. Drive-letter paths are checked on Windows.
  • Cursor adapter and Claude pre-tool-use, plus the OpenCode workdir hint.
  • Binding fallback, Session-Id trailer, and a trailer id with no event stays absent.
  • Admin-only events stay partial and print N/A. A tool call on the branch prints real counts.
  • Distinct warnings: log absent, jq missing, capture disabled, empty selection, invalid JSON lines.
